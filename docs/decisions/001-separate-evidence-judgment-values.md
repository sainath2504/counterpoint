# ADR 001 — Separate evidence, judgment, values and commentary

**Status:** accepted

A polished explanation can hide where facts stop and judgment begins. Store source text and excerpts separately from bounded assessments; store priorities separately from both. Optional model prose may challenge a deterministic analysis but never change it.

Users do more explicit work and cannot paste a document for an apparently magical answer. In return, every layer can be inspected, tested and versioned independently.
