# ADR 004 — Do not simulate a multi-agent committee

**Status:** accepted

Three named panels can imply independent agreement even when one model sees one context. Request three perspectives in one optional response and label it as one call. Never call it consensus.

The project gives up an impressive-sounding “multi-agent” label for an accurate mental model. Genuine independence would require distinct evidence access, reviewers or models and measurement of correlated failures.
