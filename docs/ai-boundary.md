# AI boundary

AI is optional commentary around a deterministic result.

One explicit action sends one Responses API request. A server-side key and model name are both required. D1 limits each user to ten attempts per hour; requests time after 45 seconds and output is capped at 4,000 tokens. Provider storage is requested as disabled. Source packets are labeled untrusted data.

The strict schema requires exactly three perspectives: advocate, skeptic and auditor. Every perspective requires a citation. Source IDs must be active and quotes must be exact excerpts. Invalid-out, refused, incomplete, malformed, and rate-limited output fails closed. No synthetic review replaces it.

Schema compliance is not truth; exact attribution is not entailment. Model prose cannot modify scores, policy, history, or execute actions.

Tests cover provider-shaped success, invented sources/quotes, malformed and incomplete responses, refusal, provider failure, bounds and usage reporting. A real-model release should add measured evaluations for groundedness, injection resistance, diversity, latency and actual cost. None are claimed until run.
